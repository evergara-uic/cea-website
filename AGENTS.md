## Token budget

At roughly 70% context usage, switch to compact output and stay compact: no
preamble, no progress narration between tool calls, batch tool calls, and do not
re-read or reprint anything already in context. Still read before editing, still
verify builds, still report failures. See `~/.config/opencode/AGENTS.md`.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
